::: {#box-key-inequality-rules .thmkey icon="rule" title="חישוב עם אי-שוויונות"}
לכל $x, y, z, c \in \mathbb{R}$:

(א) אם $x < y$ וגם $,y < z$ אז $.x < z$

(ב) אם $,x < y$ אז $.x + c < y + c$

(ג) אם $x < y$ וגם $,c > 0$ אז $.cx < cy$

(ד) אם $x < y$ וגם $,c < 0$ אז $cx > cy$ (כפל במספר **שלילי** הופך את כיוון אי-השוויון).

(ה) אם $,0 < x < y$ אז $\frac{1}{x} > \frac{1}{y}$ (היפוך של מספרים חיוביים הופך את הכיוון).
:::

::: {#box-exm-inequality-flip .thmexm title="פתרון אי-שוויון לינארי"}
נפתור $.3 - 2x < 9$

נחסר $3$ משני האגפים, לפי כלל (ב) עם $:c = -3$

$$.-2x < 6$$

נכפול את שני האגפים במספר $,-\frac{1}{2}$ כדי לבודד את $.x$ זהו מספר **שלילי**, ולכן לפי כלל (ד) כיוון אי-השוויון מתהפך:

$$.x > -3$$

הפתרון הוא כל המספרים הגדולים מהמספר $.-3$ בדיקה: עבור $x = 0$ מתקיים $,3 - 0 = 3 < 9$ ואכן $.0 > -3$
:::

::: {#box-warn-multiply-unknown-sign .thmwarn title="כפל בביטוי שסימנו אינו ידוע"}
לפני שמכפילים אי-שוויון בביטוי, צריך לדעת את **סימנו**. למשל, מ-$\frac{1}{x} < 1$ אסור להסיק $1 < x$ בלי לדעת ש-$.x > 0$ עבור $x = -1$ מתקיים $,\frac{1}{x} = -1 < 1$ אבל לא מתקיים $.1 < -1$ כשהסימן אינו ידוע, מחלקים למקרים.
:::
